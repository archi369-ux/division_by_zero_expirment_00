# Minimal Theorem List v1

This document lists the current **core claims** of the branch-arithmetic framework in compact proposition form.
It is intentionally stripped of extended commentary.

These propositions are stated relative to the current scope:

- expression language generated by `+`, `-`, `*`, `/`
- primitive zero-denominator rule `a/0 := a`
- detector functions `D_f := 1 - f/f` and `N_f := f/f`
- branch firewall
- denominator classifier with statuses `ZERO`, `NONZERO`, `UNKNOWN`
- guarded outputs in Branch Normal Form and Solution Normal Form

The list records the **current theorem-level core** of the project. It does **not** claim completeness, full confluence, field semantics, or analytic meaning.

---

## Primitive and detector propositions

### T1. Primitive zero-denominator rewrite
For every expression `A`,

`A / 0 -> A`.

### T2. Zero-numerator collapse
For every expression `B`,

`0 / B -> 0`.

In particular, `0 / 0 -> 0`.

### T3. Zero/nonzero detector partition
For every expression `f`,

`D_f + N_f = 1`.

### T4. Detector exclusivity
For every expression `f`,

`D_f * N_f = 0`.

### T5. Detector agreement with branch guards
Whenever `f = 0`, the corresponding zero branch may be guarded by `D_f = 1`; whenever `f != 0`, the corresponding NZ-branch may be guarded by `N_f = 1`.

---

## Branch and normalization propositions

### T6. Branch firewall
No rewrite requiring the assumption `B != 0` may be applied to a quotient `A / B` before branch split on `B`.

### T7. Branch-split rule for quotients
For a quotient `A / B`, evaluation proceeds by classifying `B` as `ZERO`, `NONZERO`, or `UNKNOWN`.

### T8. Zero-classified quotient rule
If the denominator of `A / B` is classified as `ZERO`, then the quotient reduces to the numerator:

`A / B -> A`.

### T9. Nonzero-classified quotient rule
If the denominator of `A / B` is classified as `NONZERO`, then ordinary division laws are admissible for that quotient.

### T10. Unknown-classified quotient rule
If the denominator of `A / B` is classified as `UNKNOWN`, then the quotient persists as a guarded branch object with both zero and nonzero branch attempts.

### T11. Branch Normal Form existence (operational)
Every expression in current scope admits an operational Branch Normal Form obtained by recursive denominator classification and guarded branch expansion.

---

## Hidden-zero propositions

### T12. Obvious-zero detection
The denominator classifier detects literal and directly reducible zeros, including instances generated by rules such as:

- `x - x -> 0`
- `0 * x -> 0`
- `x / 0 -> x`
- `(x / 0) - x -> 0`

### T13. Additive hidden-zero detection
The denominator normalizer reduces additive hidden-zero forms to `0` whenever they are reachable by signed-sum canonicalization, opposite-term cancellation, and zero cleanup.

Representative family:

`(u - v) + (v - u) -> 0`.

### T14. Pairwise factor hidden-zero detection
The denominator normalizer reduces pairwise common-factor hidden-zero forms to `0` whenever zero is exposed by exact duplicate cancellation or safe common-factor extraction.

Representative family:

`x*y - y*x -> 0`.

### T15. Bounded distributive hidden-zero detection
The denominator normalizer reduces bounded multi-term distributive zero forms to `0` whenever one-way grouping exposes immediate cancellation.

Representative family:

`a*b + a*c - a*(b + c) -> 0`.

## Expression-level branch propositions

### T16. Expression branch recursion
If a subexpression denominator is classified before its parent quotient, then the resulting parent expression is formed by taking the guarded branch product of the child branch outputs.

### T17. Branch pruning
Any branch whose guard is contradictory or impossible is removed from the final branch object.

### T18. Branch merging
If two surviving branches have equivalent resulting expressions and compatible guards, they may be merged into a single branch.

## Equation-solver propositions

### T19. Solution Normal Form
The official output of the solver is a finite family of guarded clauses of the form

`[guard] -> solution`.

### T20. Soundness of `A/B = C`
The equation

`A / B = C`

has the branch-local solver decomposition:

- `[B = 0] -> solve(A = C)`
- `[B != 0] -> solve(A = B*C)`

with detector-backed guards whenever available.

### T21. Soundness of `C = A/B`
The equation

`C = A / B`

has the branch-local solver decomposition:

- `[B = 0] -> solve(C = A)`
- `[B != 0] -> solve(B*C = A)`

### T22. Soundness of `A/B = C/D`
The equation

`A / B = C / D`

has the branch-local solver decomposition:

- `[B = 0, D = 0] -> solve(A = C)`
- `[B = 0, D != 0] -> solve(A*D = C)`
- `[B != 0, D = 0] -> solve(A = B*C)`
- `[B != 0, D != 0] -> solve(A*D = B*C)`

### T23. Soundness of `A/B = A`
The equation

`A / B = A`

has guarded solutions obtained by splitting on `B`, with the zero branch reducing to the tautology `A = A` and the NZ-branch reducing to `A = A*B`.

### T24. Soundness of pruning and merging in solver output
If a solver branch has an impossible guard, it may be discarded without loss of valid solutions. If two branches yield the same solution set under compatible guards, they may be merged without loss of valid solutions.

## Stability and scope propositions

### T25. Classification stability on tested families
Under mandatory canonicalization, one-way bounded grouping, and the branch firewall, denominator normalization is classification-stable on the currently tested additive, factorized, and bounded distributive hidden-zero families.

### T26. NZ-locality of unrestricted algebra
Any algebraic step that relies on denominator nonzero is valid only on an NZ-branch or after denominator classification as `NONZERO`.

### T27. Non-claim on full confluence
The current theory does not claim global unrestricted algebraic confluence.

### T28. Non-claim on completeness
The current theory does not claim full completeness for hidden-zero detection or general symbolic equation solving.

## Minimal current core

The present formal core of the project is the conjunction of:

- primitive quotient semantics,
- detector-backed guards,
- branch firewall,
- denominator classification,
- hidden-zero normalization,
- Branch Normal Form,
- Solution Normal Form,
- branch-local soundness of Solver Kernel v1.
